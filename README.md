# Horizon Frontier

A responsive, Horizon-inspired landing page and playable browser prototype built with vanilla HTML, CSS, and JavaScript.

## Features
- Frontier-themed landing page with machine field guide and missions
- Playable survival arena with keyboard/pointer controls
- Expedition atlas with **40 gear and supply entries** and **60 locations** across five regions
- Searchable, filterable catalog in `atlas.html`

## Play and explore
Open `index.html` in a browser to play the survival prototype. Open `atlas.html` to browse the gear catalog and locations, or serve this folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` and choose `atlas.html` for the expedition atlas.

### Game controls
- Move: **WASD** or **arrow keys**
- Aim: **mouse** or **touch**
- Fire: **click**, **Space**, or **Enter**
- Pause: **P**
