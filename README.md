# Horizon Frontier

A responsive fan-made browser game and expedition archive made with HTML, CSS, JavaScript, and Canvas.

## Play
Open `index.html` to enter the project hub, then select **Enter the frontier**. The game is a top-down exploration and survival prototype with a large scrolling world, three biomes, machine waves and boss encounters, salvage and healing pickups, a compass/minimap, two weapons, and a dash move. The atlas is in `atlas.html`.

Run locally with `python3 -m http.server 8000`, then open `http://localhost:8000`.

### Controls
- Move: **WASD** or arrow keys
- Aim: mouse
- Fire: click or **Space**
- Dash: **Shift**
- Switch weapon: **1** / **2**
- Pause: **P**

This is a browser-based prototype, not a Unity or Unreal Engine project. Unreal Engine 4.72 is not a standard released version number; if you meant Unreal Engine 4.27 or a specific Unity version, provide that target and I can prepare a matching engine project structure separately.
