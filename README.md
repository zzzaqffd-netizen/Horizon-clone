# Horizon Clone

A small Horizon-inspired landing page and interactive prototype built as a static web project.

## Features
- Futuristic wilderness aesthetic
- Responsive layout
- Animated hero panel
- Interactive mission cards and machine roster

## Run locally
Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
