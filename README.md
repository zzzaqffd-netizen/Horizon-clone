# Horizon Frontier

A responsive, Horizon-inspired landing page and playable browser prototype built with vanilla HTML, CSS, and JavaScript.

## Features
- Frontier-themed landing page with world, machine, story, and expedition sections
- Machine roster and mission cards rendered from JavaScript data
- Playable top-down survival arena: move, aim, fire, collect salvage, and survive machine waves
- Keyboard and pointer controls, pause/restart, health, score, and wave tracking
- Responsive layout and reduced-motion-friendly visual effects

## Play
Open `index.html` in a browser, or serve this folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` and select **Start mission**.

### Controls
- Move: **WASD** or **arrow keys**
- Aim: **mouse** or **touch**
- Fire: **click**, **Space**, or **Enter**
- Pause: **P**
